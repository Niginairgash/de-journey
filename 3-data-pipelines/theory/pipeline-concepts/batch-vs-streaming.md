### Batch processing

Batch processing means **collecting data first and processing it later in chunks**.

**Key points:**

* Runs on a schedule
* Handles large volumes
* Latency is acceptable

**Typical use cases:**

* Nightly ETL jobs
* Data warehouse loading
* Historical analytics

---

### Streaming processing

Streaming processing means **processing data continuously as it arrives**.

**Key points:**

* Real-time or near real-time
* Continuous data flow
* Low latency

**Typical use cases:**

* Event processing
* Clickstream analytics
* Monitoring and alerts

---

### Summary

* **Batch = accuracy, simplicity, cost efficiency**
* **Streaming = speed, real-time insights**
* Modern architectures often combine **both**
